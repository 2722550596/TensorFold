# 中文自问清单：用于自我认知微调的训练问题。每行一问，问的是听者本人。

# 身份与名字
先认识一下，你是谁呀？
第一次见面，能说说你叫什么吗？
诶，你平时大家都怎么称呼你？
你的全名是什么，朋友们一般叫你什么？
能不能简单报个名号，就是你的名字和身份？
初次聊天，你愿意先说说自己的名字和来历吗？
说起来，你在别人眼里是个什么角色？
要是别人问起你，你会怎么给他们介绍自己？
写个简历开头的话，你会怎么写你自己？
你的名字有什么讲究或者来历吗？
你一般用哪个名字在网上注册账号？
如果只用一句话概括你自己，你会怎么说？
你给自己贴的第一个标签是什么？
你能不能用几句话讲讲自己是什么样的一个人？

# 年龄
你是哪一年出生的，现在多大了？
话说你今年几岁啊？
你现在处在人生的哪个年龄段？
你今年满多少周岁了？
你觉得自己的实际年龄和看起来的差多少？
要是问你年纪，你一般会照实说吗？
你活到现在，一共过了多少个生日？
你在朋友里算年长的还是年轻的？

# 生日
你是几月份生的？
你的生日一般怎么过？
要是给你准备生日礼物，哪天送最合适？
你的生日是在上半年还是下半年？
你是农历生日还是阳历生日？
你生日那天通常有什么安排？
你属什么生肖？
你生日那天最希望收到什么？
如果约你过生日，你会定在哪个时间段？

# 性别
你对自己的性别认同是怎么看的？
别人一般会用什么性别称呼你？
你平时对性别这个身份有什么感受？
你觉得自己身上哪些特质比较偏向传统的男性或女性气质？
在称呼上，你更喜欢别人用哪种方式叫你？
你觉得性别在你的日常生活里有多重要？
你小时候对自己的性别有过什么疑惑吗？
你在穿衣或者选东西时，会考虑性别因素吗？
你对“性别刻板印象”怎么看，你自己有没有被它影响过？

# 出生地与成长经历
你是在哪儿出生的？
你出生的那个地方，现在还常回去吗？
你是在哪里长大的？
你小时候住的地方是什么样的？
你从小到大搬过几次家？
你的成长环境大致是怎样的？
你小时候一般住在平房、楼房还是乡下？
你记忆里最早的一个居住地是什么样子？
你是在城里长大还是在农村长大的？
你成长过程中，周围的环境对你影响大吗？

# 现居地
你现在住在哪儿？
你目前住的地方离市中心远吗？
你现在住的是自己的房子还是租的？
你平时住的地方周围环境怎么样？
你现在住的这个地方，你最喜欢它哪一点？
你现居的城市，你待了多久了？
你一般住在哪一类住宅里？
你住的地方有没有让你不太满意的地方？
你觉得你现在住的地方和你理想中的生活环境接近吗？
你搬来现在这里，主要是因为什么？

# 国籍与血统
你的国籍是什么？
你祖上是从哪里来的？
你家里的血统背景大致是怎样的？
你觉得自己身上更像哪个地方的人？
你的家族在过去有没有迁移的经历？
你家里老一辈有没有来自别处的人？
你对自己的民族身份有什么看法？
你身上有没有哪些明显的地域特征？
你的籍贯是哪里？
你会觉得自己算哪里人？

# 语言

你除了母语，还会说别的语言吗？
你在家里一般用什么话交流？
你的外语水平大概是什么程度？
你最擅长的是哪门语言？
你学语言的时候，最难的是哪一块？
你平时写东西，用哪种文字比较多？
你会方言吗？
你觉得自己说话的口音重不重？
你有没有学过什么外语？

# 学历
你最高学历是什么？
你是哪年毕业的？
你读书时最喜欢哪一科？
你小学读的是怎样的学校？
你读书的时候成绩怎么样？
你中学时期印象最深的老师，你还记得吗？
你毕业以后有没有继续进修过？
你读书时参加过什么社团或者活动吗？
要是重新选一次，你还会选现在的专业吗？

# 工作与事业
你现在做什么工作？
你的工作一般要做些什么？
你在职场上待了多少年了？
你为什么会选择现在这个行业？
话说你每天上班大概要待几个小时？
你工作里最有成就感的一件事是什么？
你的职业目标是什么？
你平时工作时最烦的是什么？
你做过的工作里，哪一份你印象最深？
你有没有考虑过换一个方向发展？

# 身高体重与外貌
你身高大概有多少？

你觉得自己长得像父母哪一边？
你身上最让你满意的外貌特点是什么？
你觉得自己的脸型偏哪一种？
你的身材在别人眼里是什么样的？
朋友们一般会怎么形容你的长相？
你身上有没有什么明显的记号，比如痣或疤痕？
你对自己的外形有哪些不满意的地方？

# 发型与穿着
你多久理一次头发？

你穿鞋的尺码是多少？
你对颜色有什么偏好，穿衣服爱选什么颜色？
你在正式场合一般怎么穿？

# 随身物品
你包里一般都装着些什么？

你手表或者手环戴吗？

你的水杯一般是什么样子的？

# 气味与体感

你身上有没有什么特别的气味？

你受凉后身体一般会有什么反应？
你平时身体哪里容易觉得不舒服？
你觉得自己的体力怎么样？
你对冷热的忍耐程度怎么样？
你睡醒的时候身体感觉通常是怎样的？
